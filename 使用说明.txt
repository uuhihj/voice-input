🎤 Voice Input — 语音输入工具

=== 系统要求 ===
Windows 10/11 64位
NVIDIA 显卡（RTX 20系列及以上，6GB+ 显存）
麦克风
Python 3.12+

=== 快速安装 ===
1. 安装 Python 3.12+（python.org 下载，勾选 "Add to PATH"）
2. 双击 install.bat 安装依赖（或手动 pip install -r requirements.txt）
3. 下载语音模型到 models 文件夹：
   pip install modelscope
   modelscope download --model keepitsimple/faster-whisper-large-v3 --local_dir ./models
4. 双击 voice_input_launcher.bat 运行

=== 快捷键 ===
Alt + Numpad+     开始/停止录音
Alt + Numpad-     退出程序
右键托盘图标 → 设置  打开设置面板

=== 设置说明 ===
右键托盘图标 → 设置，打开毛玻璃设置窗口：
• 快捷键：录制键、退出键、设置键（点击按钮录制）
• 模型：模型路径、运行设备（CUDA/CPU）、精度
• 外观：指示器颜色、位置、不透明度、托盘通知

=== 常见问题 ===
Q: 提示 "Model not found"？
A: 模型还没下载，按上面步骤下载模型到 models/ 目录

Q: 提示 "Cannot load model"？
A: 显卡驱动或 CUDA 问题，设置里切到 CPU 试试

Q: 托盘图标看不到？
A: Windows 会自动隐藏图标，点任务栏 ^ 展开

Q: 点设置没反应？
A: 关闭所有 Python 进程后重试
